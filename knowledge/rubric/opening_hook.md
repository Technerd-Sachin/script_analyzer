Judge only the first 3 lines, about the first 5 seconds of a vertical episode. Viewers swipe away within seconds, so the hook must land before any setup. Credit a line or image that makes the viewer need an answer. Greetings, establishing description and backstory score 1-2. Cite the hook line IDs.
